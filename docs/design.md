## 遮蔽

- 直射（銃弾・水平に飛ぶ砲弾・光線）が地上ユニットを狙うとき、目標から 8m 以内に射線より高い遮蔽物があれば、家・城壁・岩・城門の塔と壁は 50%、木は 25% の確率で弾を止める。止まった銃弾は遮蔽物に当たり、砲弾はそこで炸裂する。
- 曲射（臼砲）・爆撃・近接攻撃・炎は遮蔽を無視する。空中の目標と建物は遮蔽を受けない。低い岩は歩兵を隠せても、背の高い歩行機や巨人は隠せない。
- 遮蔽の高さと種類は地形生成が歩行グリッドと同じ 2m 格子で `cover.bin` に書く（下位7ビットが 0.25m 単位の高さ、最上位ビットが家・城壁・岩）。城門の分は、門が立っている間だけ実行時に足す。

## 経済

- 資材・エーテルは毎分の収入制（本拠地＋精製所＋占領都市）。人口上限は本拠地 20＋居住区 15＋都市 10（上限 160）。
- 建設は本拠地の半径 62m、城門の 26m、自軍都市の半径＋20m の範囲。平坦さと通行可能セルを確認する。
- ブラスホルム を持つ陣営は生産速度 +15%。

## マップ（Ironspine Crossing, 400m 四方）

- 北西→南東に渓谷。中央は湖に囲まれたメサ（中央ネクサス）で、両岸へ橋が1本ずつ。北西と南東にも橋。
- 3ルート: 西（西の鋳造所→北西の橋→北の中継塔）、中央（ブラスホルム→2本の橋→エーテル工廠）、南（南の工房→南東の橋→東の砦）。
- 川は段差ごとに水位を持ち、段差に滝。崖の滝4つ。高さ場は 321×321（1.25m 間隔）、歩行グリッドは 2m。
- 歩行グリッドでは都市の家・城壁・大きな岩・木を通れない（家などはモデルの大きさ、木は一番下の枝の広がりから範囲を決める）。城門は塔と壁だけがふさがり、アーチの下は通れる。

## ミッション進行

ミッションは `game/scenarios/*.json` のシナリオとして書き、`Mission` が読み込んで実行する（形式は [scenarios.md](scenarios.md)）。
内蔵の「アイアンスパインの門」の流れ:

| 時刻 | 出来事 |
|---|---|
| 0:55 / 2:10 / 3:30 / 4:50 | 敵の攻撃波（難易度で人数 0.75〜1.35 倍） |
| 5:30 | 援軍到着・資源ボーナス。以後は敵AIが通常の攻勢に移る |
| 以降 | 中央ネクサス占領 → 敵本拠地破壊で勝利 |

門が落ちても敗北にはならない（目標が「失敗」表示になる）。本拠地の喪失のみ敗北。

## セーブ

- `user://saves/slot1〜3.json` に JSON で保存する。中身はプレイヤーの資源と統計、都市、建物（建設・生産の進み具合）、ユニット（体力・命令・構え／展開）、霧の探索済みマップ、シナリオの進行（変数・発火済みトリガー・目標）、敵AI、カメラ。
- 飛んでいる砲弾とエフェクトは保存しない。ロード時はマップから都市だけを置き、城門を含む建物とユニットはセーブから作り直す。

## 描画と性能

- レンダラーは Mobile（内蔵 GPU で Forward+ より約30%速い）。画質プリセットは解像度倍率 0.67/0.8/1.0、影の距離と解像度を変える。
- 歩兵は模型1つを頂点カラー（色・部位ID）と UV（金属度・粗さ）/UV2（チーム色・発光）に焼き込み、MultiMesh 1回の描画で全員を描く。脚の振りと射撃反動は頂点シェーダー。
- 神獣は Blender でメタボールの体を骨に自動ウェイトで乗せたスキンメッシュ（`tools/blender/models/creatures.py`）。歩き方・羽ばたき・攻撃・死は Godot 側で骨を回して作る。スキンメッシュのテクスチャは三面投影だと骨の動きで滑るので、UV（静止姿勢での箱投影）で貼る。
- エフェクトは CPU 計算のビルボード粒子を MultiMesh で描く（層ごとに1描画）。煙突の煙と滝のしぶきは発生位置が固定なので、頂点シェーダーが周期再生する（毎フレームの CPU 更新なし）。
- 戦場の霧は 4m 格子の視界を 5Hz で更新し、画面全体の霧オーバーレイ（深度から地表位置を復元）で暗くする。

## ブラウザ版とタッチ操作

- ブラウザ版は Godot の Web 書き出し（スレッドなし、WebGL 2 の Compatibility レンダラー）を GitHub Pages に置く。サーバー側の処理はなく、COOP/COEP ヘッダーも要らない。main への push で Actions が Godot と Web テンプレートを取り、書き出して載せる。
- Compatibility では深度の範囲と色の扱い（sRGB のまま来る）が違うので、シェーダーは `compat.gdshaderinc` の関数を通す。影つきの太陽光が別の描画パスで足されて明るくなるため、太陽・露出・霧の値を Compatibility 用に変えて見た目を合わせている（`env_rig.gd`）。
- OS のフォントを使えないので、Noto のサブセットを全プラットフォームで同梱する。ゲームの文字がフォントにないと書き出しが止まる（`check_glyphs.gd`）。
- タッチ端末（`Game.compact`）では、UI を CSS px 基準で大きさを決め（1単位は最大 1.25px、画面は最低 1000x480 単位）、HUD を小画面用に組む。縦向きのときは横向きにするよう全面に表示する。
- 指の操作は `TouchControls` が読む。HUD の上で始まった指は HUD のもの。Godot の GUI はタッチを止めないので、「その指から作られたマウスクリックが GUI を素通りしたか」で判定する。戦場で始まった指は離すまで追う。
- タップは右クリックに当たる命令も兼ねる（選択中なら移動・攻撃・修理・集結地点）。選択の解除は長押しか選択パネルのボタン。建設は置き場所を2回のタップで確かめる（誤って建てないため）。
- ブラウザは指の操作に合わせて本物のマウスの移動も送ってくるので、タッチから 0.8 秒以内のマウスは指のものとして扱う。

## 天罰の塔（マップ兵器）

- 建設メニューの「祠・塔」から建てる。1人1基、資材 600・エーテル 600、建設 90 秒。
- 240 秒で充填し、マップのどこへでも撃てる（ミニマップでも狙える）。撃つと両陣営に着弾地点の警告（赤い輪と光）が出て、10 秒後に半径 22m へ最大 1400 のダメージ（中心から離れると 35% まで減る）。味方は巻き込まない。
- 本拠地と城門は1発で最大体力の 30% までしか削れない。着弾前に塔を壊すと中止になる。
- 巨神と天罰の塔は「強いが止められる」ように作る: 巨神は寿命と1体の制限、塔は長い充填・事前の警告・本拠地への上限・塔を壊せば中止。敵AIは 13 分以降に巨神を作り、巨神の光も使う（特殊能力を使う敵AIはこれだけ）。
- 敵AIは 600 秒に建て、充填が終わると「プレイヤーの部隊と建物が最も密集した所」（費用で重みづけ）を狙う。敵の塔が完成するとプレイヤーに警告が出る。

## 表記

- 画面の表記は日本語にする（ボタン・ユニット名・建物名・資源・メニュー・ミッションの見出し）。ユニットと建物の表示名は `Defs` の `name`（王冠 / ヴァルケシュ）、ボタンには短い `short` を使う。ロゴ「AETHER CROWN」と都市名は固有名として英字のまま。

## やらないこと

- 既存の商用ゲームの名称・アセットは使わない。
- 人同士のネット対戦（同期・部屋・接続のためのサーバーが要る）は、ゲームをもう少し作り込むまで入れない。
- 外部アセットのダウンロードなど、遊ぶのに外部サービスが要る作りにはしない（ブラウザ版も静的なファイルだけで動く）。
