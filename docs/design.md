## 遮蔽

- 直射（銃弾・水平に飛ぶ砲弾・光線）が地上ユニットを狙うとき、目標から 8m 以内に射線より高い遮蔽物があれば、家・城壁・岩・城門の塔と壁は 50%、木は 25% の確率で弾を止める。止まった銃弾は遮蔽物に当たり、砲弾はそこで炸裂する。
- 曲射（臼砲）・爆撃・近接攻撃・炎は遮蔽を無視する。空中の目標と建物は遮蔽を受けない。低い岩は歩兵を隠せても、背の高い歩行機や巨人は隠せない。
- 遮蔽の高さと種類は地形生成が歩行グリッドと同じ 2m 格子で `cover.bin` に書く（下位7ビットが 0.25m 単位の高さ、最上位ビットが家・城壁・岩）。城門の分は、門が立っている間だけ実行時に足す。

## 経済

- 資材・エーテルは毎分の収入制（本拠地＋精製所＋占領都市）。人口上限は本拠地 20＋居住区 15＋都市 10（上限 160）。
- 建設は本拠地の半径 62m、城門の 26m、自軍都市の半径＋20m の範囲。平坦さと通行可能セルを確認する。
- Brassholm を持つ陣営は生産速度 +15%。

## マップ（Ironspine Crossing, 400m 四方）

- 北西→南東に渓谷。中央は湖に囲まれたメサ（Central Nexus）で、両岸へ橋が1本ずつ。北西と南東にも橋。
- 3ルート: 西（West Foundry→北西の橋→North Relay）、中央（Brassholm→2本の橋→Aether Works）、南（South Works→南東の橋→East Bastion）。
- 川は段差ごとに水位を持ち、段差に滝。崖の滝4つ。高さ場は 321×321（1.25m 間隔）、歩行グリッドは 2m。
- 歩行グリッドでは都市の家・城壁・大きな岩・木を通れない（家などはモデルの大きさ、木は一番下の枝の広がりから範囲を決める）。城門は塔と壁だけがふさがり、アーチの下は通れる。

## ミッション進行

ミッションは `game/scenarios/*.json` のシナリオとして書き、`Mission` が読み込んで実行する（形式は [scenarios.md](scenarios.md)）。
内蔵の「アイアンスパインの門」の流れ:

| 時刻 | 出来事 |
|---|---|
| 0:55 / 2:10 / 3:30 / 4:50 | 敵の攻撃波（難易度で人数 0.75〜1.35 倍） |
| 5:30 | 援軍到着・資源ボーナス。以後は敵AIが通常の攻勢に移る |
| 以降 | 中央ネクサス占領 → 敵本拠地破壊で勝利 |

門が落ちても敗北にはならない（目標が「失敗」表示になる）。本拠地の喪失のみ敗北。

## セーブ

- `user://saves/slot1〜3.json` に JSON で保存する。中身はプレイヤーの資源と統計、都市、建物（建設・生産の進み具合）、ユニット（体力・命令・構え／展開）、霧の探索済みマップ、シナリオの進行（変数・発火済みトリガー・目標）、敵AI、カメラ。
- 飛んでいる砲弾とエフェクトは保存しない。ロード時はマップから都市だけを置き、城門を含む建物とユニットはセーブから作り直す。

## 描画と性能

- レンダラーは Mobile（内蔵 GPU で Forward+ より約30%速い）。画質プリセットは解像度倍率 0.67/0.8/1.0、影の距離と解像度を変える。
- 歩兵は模型1つを頂点カラー（色・部位ID）と UV（金属度・粗さ）/UV2（チーム色・発光）に焼き込み、MultiMesh 1回の描画で全員を描く。脚の振りと射撃反動は頂点シェーダー。
- 神獣は Blender でメタボールの体を骨に自動ウェイトで乗せたスキンメッシュ（`tools/blender/models/creatures.py`）。歩き方・羽ばたき・攻撃・死は Godot 側で骨を回して作る。スキンメッシュのテクスチャは三面投影だと骨の動きで滑るので、UV（静止姿勢での箱投影）で貼る。
- エフェクトは CPU 計算のビルボード粒子を MultiMesh で描く（層ごとに1描画）。煙突の煙と滝のしぶきは発生位置が固定なので、頂点シェーダーが周期再生する（毎フレームの CPU 更新なし）。
- 戦場の霧は 4m 格子の視界を 5Hz で更新し、画面全体の霧オーバーレイ（深度から地表位置を復元）で暗くする。

## やらないこと

- 外部サービスへの依存（オンライン機能・外部アセットのダウンロード）は入れない。
